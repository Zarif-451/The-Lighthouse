The Problem
Why Does Mental Wellbeing Go Untracked?

No Structured Habit

People want to reflect on their mood and mental state daily, but have no guided framework to do it consistently.

Fear of Privacy Invasion

Most organisational wellness tools are rejected by users because they fear their personal reflections are being read by managers.

No Longitudinal Insight

Standalone mood apps capture a single moment but never correlate sleep, stress, activity, and behaviour over time.

No Gentle Intervention

Admins or counsellors have no visibility into who may need a gentle check-in — until it's already too late.

Introduction
What is Lighthouse?
  • A personal wellbeing web app that guides users through a short daily journey of check-in, scenario, visual reflection, and journaling.
  • Tracks patterns over time and surfaces personal insights — mood, sleep, energy, productivity, behaviour.
  • Includes a separate Admin Portal where staff can monitor overall platform health and support at-risk users — without ever reading private journal entries.
  • Built for schools, organisations, or any community that needs to support people's mental wellbeing responsibly.

Guided Journey — Steps 1 & 3, 5, 7, 9, 11
Daily Check-in & Scenario Assessment
Step 1 — Daily Check-in
Users log sleep hours, mood (1–5), energy, productivity, and physical activity. Structured sliders take under a minute and feed all longitudinal charts.
Steps 3, 5, 7, 9, 11 — Scenario Assessment (×5)
Five scenario rounds are woven throughout the journey, each presenting a short situational story. Drawn from an 80+ item bank, they probe behavioural coping patterns without clinical framing.
Guided Journey — Steps 6 & 13
Visual Reflection & Private Journal
  • Step 6 — Visual Reflection: User picks an image that matches their current emotional state — Calm, Heavy, Overwhelmed, Hopeful, etc. Adds a qualitative mood signal beyond numbers.
  • Step 13 — Reflection Journal (optional): A free-text canvas for unconstrained personal writing. Guided prompt cards help users who aren't sure where to start.
  • Journal text is protected by Supabase Row Level Security (RLS) — only the author's session can read it. Admins see no journal content, by design.
Reflection Journal — private, prompt-guided writing canvas
Personal Analytics
Insights & PDF Reports
Insights Page
Behavioural pattern dashboard powered by Chart.js. Correlates sleep, mood, energy, productivity, and scenario scores across days and weeks — unlocking after 7+ check-ins.
Weekly / Monthly Reports + PDF Export
Summarises the user's journey into readable weekly and monthly snapshots. One-click PDF export (jsPDF) compiles all charts and scores for personal records or therapy consultations.
AI Companion — context-aware wellbeing chat
AI Feature
AI Companion — Lighthouse Chat
  • Powered by Groq's Llama-3.3-70B model via a secure Express proxy server — the API key never reaches the browser.
  • Receives a live context snapshot of the user's own data: dashboard stats, recent check-ins, journey progress, and streaks.
  • Answers questions like "Summarise my week", "What's my mood trend?", or "What should I focus on today?" — grounded in actual data, never fabricated.
  • Strictly scoped: cannot diagnose conditions, cannot see any other user's data, and refuses to invent scores.
Admin Portal
Platform Monitoring & Care Panel
Admin Dashboard & Analytics
A bird's-eye view of the whole platform: total users, daily activity, growth charts, flagged counts, and PDF report packs. Journal text is never shown here by design.
Care Panel — Watchlist & Nudges
Flagged users (via heuristics: low mood streaks, inactivity, avoidance patterns) appear here. Admins review attention signals, add private notes, send a soft nudge, or place users on a 7-day watchlist.
Admin Portal
User Directory & Scenario Management
User Directory
Admins browse all registered users, view engagement status, and surface accounts that may need a care action — with no access to private journal or reflection content.
Scenario Bank Management
Admins create, edit, enable, or disable scenario items. The bank ships with 80+ seed scenarios and can be expanded to match the organisation's context or user population.
Architecture
Technology Stack
Frontend
Vanilla HTML / CSS / JS
Static multi-page app — intentionally no framework. Fast, zero-build, deployable to any static host.
Database & Auth
Supabase (Postgres + RLS)
Row Level Security enforces the privacy boundary at the DB layer — users can only see their own rows.
AI Backend
Groq · Llama-3.3-70B
Express.js proxy server holds the Groq API key server-side, feeds the model a live user data snapshot per request.
Data Visualisation
Chart.js
Renders all mood, sleep, energy, productivity and behavioural trend charts on the dashboard and insights pages.
PDF Export
jsPDF (client-side)
Generates wellness reports and admin PDF packs (Platform Snapshot, Engagement Pack, Flagged Care Summary) entirely in the browser.
Hosting
Vercel (Static Deploy)
Deployed via vercel.json. Any static host works — no build step. Supabase config injected via config.js.
Conclusion
What Lighthouse Delivers

Guided Daily Habit: A 13-step journey building consistent self-reflection — check-ins, scenarios, behavioural activities, visual, and journal.

Bulletproof Privacy: Supabase RLS means journal entries are cryptographically scoped to the user. Admins see signals, never diaries.

Personal Insights: Longitudinal charts surface mood-sleep-energy correlations that a single-point wellness check could never reveal.

Compassionate Admin Care: Heuristic flagging + soft nudges let admins reach out proactively — as a care tool, not a surveillance tool.

AI Companion: Context-aware Groq-powered assistant grounded in the user's real data — no hallucinated scores, no generic advice.

Future Roadmap: Component framework migration, mobile app, and predictive anomaly detection for admin care signals.
